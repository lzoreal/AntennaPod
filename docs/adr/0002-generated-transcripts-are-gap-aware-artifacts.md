# 生成转录是增量持久化、缺口感知的单语产物，官方转录优先

**Status**: accepted

生成转录复用现有 word-JSON 契约（`segments` + `words` + `audio_seconds`）和 `Transcript` 模型，但它的来源与官方转录不同：官方转录整份可用且有双语，生成转录只能按播放进度一段段产出。因此定下三条边界：有官方转录时不生成；生成结果按句/每 30 秒 checkpoint 增量写入现有 `.transcript` sidecar，不重复识别已覆盖区间，只补缺口；缺口由 UI 按相邻段时间差标注，不写占位段落。模型按语种拆成两个 int8 小模型（中/英），由 `feed.language` 加用户默认语言选择，只下载用到的那个；混合语言单集接受降级。生成转录的时间戳来自解码样本，天然对齐，因此隐藏时间偏移控制；模型升级不提示、不自动重生成，整集重生成由转录页的二级入口手动触发。

**Considered Options**: 只存内存（切集/重听后重新识别，无法搜索、偏移或合并）；中英双语单模型（对混合语音更好，但与“只下需要的语种”冲突）；官方与生成并存切换（要维护两份偏移与高亮来源）。

**Consequences**: 需要维护媒体时间覆盖索引与 checkpoint 合并逻辑；生成转录可能长期不完整；官方转录加载失败时不会用生成转录兜底；模型或模型语言变化不会改写已有产物。
